# Security policy

## Supported versions

FuncyTown is pre-1.0. Until 1.0 is tagged, only the **latest published prerelease** receives security fixes. After 1.0 ships, this section will be updated to list every supported minor version.

| Version | Supported |
|---|---|
| `0.1.x` (latest) | ✅ |
| Older / unreleased | ❌ — please upgrade |

## Reporting a vulnerability

**Please do not open public GitHub issues for security reports.**

Use one of:

- GitHub's private vulnerability reporting: <https://github.com/mhagrelius/FuncyTown/security/advisories/new>
- Email: `matthew@hagreli.us`

Include:

- A description of the issue and its potential impact.
- Reproduction steps or a proof-of-concept.
- The FuncyTown version (NuGet package version or git SHA).
- Any suggested mitigation, if you have one.

You can expect:

- An acknowledgement within **3 business days**.
- An update on the assessment within **7 business days**.
- A coordinated fix and disclosure timeline; credit in the release notes if you'd like it.

Thanks for helping keep FuncyTown and its consumers safe.
