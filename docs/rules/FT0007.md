# FT0007 — FuncyTown Result alias must be partial

| | |
|---|---|
| **Severity** | Error |
| **Category** | FuncyTown.Generation |
| **Code fix** | No |

## Cause

A type decorated with `[Result<…>]` is declared without the `partial` modifier. The source generator emits additional members into a partial declaration; without `partial`, no generated code can land.

## How to fix

Add `partial` to the declaration:

```csharp
[Result<User, UserError>]
public readonly partial record struct UserResult;
```
