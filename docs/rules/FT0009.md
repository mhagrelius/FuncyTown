# FT0009 - Result alias cannot declare primary constructor parameters

| | |
|---|---|
| **Severity** | Warning |
| **Category** | FuncyTown.Generation |
| **Code fix** | No |

## Cause

A type decorated with `[Result<...>]` declares one or more primary constructor parameters. FuncyTown Result aliases are generated wrappers around `Result<T, TError>` state. Extra primary-constructor parameters create independent record state that the generated `Success` and `Failure` factories cannot initialize correctly.

## How to fix

Remove the primary constructor parameters from the alias declaration:

```csharp
[Result<int, string>]
public readonly partial record struct OperationResult;
```

If the value belongs to the successful result, move it into the success type:

```csharp
public sealed record OperationValue(int Value, string MyVal);

[Result<OperationValue, string>]
public readonly partial record struct OperationResult;
```
