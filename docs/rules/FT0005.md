# FT0005 — Subclass of [ErrorUnion] base is missing [ErrorCase]

| | |
|---|---|
| **Severity** | Error |
| **Category** | FuncyTown.Analyzers |
| **Code fix** | No |

## Cause

A type inherits (directly or indirectly) from a class marked `[ErrorUnion]` but is not itself marked `[ErrorCase]`. The generated union therefore does not include this case.

## Why this matters

The whole point of `[ErrorUnion]` is closed exhaustiveness: every reachable subclass must be visible to the generator. Missing `[ErrorCase]` silently hides the case from `Match`/`Switch`.

## How to fix

Mark the subclass:

```csharp
[ErrorCase]
public sealed partial class NotFound(Guid id) : UserError
{
    public Guid Id { get; } = id;
    public override string Message => $"User '{Id}' was not found.";
}
```
