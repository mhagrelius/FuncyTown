# FT0008 — Generated type cannot be nested in a file-local type

| | |
|---|---|
| **Severity** | Error |
| **Category** | FuncyTown.Generation |
| **Code fix** | No |

## Cause

A `[Result<…>]`-decorated alias (or `[ErrorUnion]` type) is nested inside a `file`-scoped containing type. File-local type identity is restricted to a single source file, so generated partial declarations cannot extend the type from a separate `.g.cs` file.

## How to fix

Move the alias out of the file-local type, or remove the `file` modifier from the containing type:

```csharp
// Before — won't generate
file class Holder
{
    [Result<int, MyError>]
    public readonly partial record struct IntResult;
}

// After
internal class Holder
{
    [Result<int, MyError>]
    public readonly partial record struct IntResult;
}
```
